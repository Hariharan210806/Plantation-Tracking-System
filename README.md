# Waste Management System

A Java console-based application for managing waste collection records.

## Features

- Add Waste
- View All Waste
- Search Waste
- Update Waste
- Delete Waste
- Exit

## Waste Details

The system stores:

- Waste ID
- Waste Type
- Quantity
- Location
- Collection Date

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming
- Git & GitHub

## Project Structure

- `Main.java` - Main application, menu and waste management operations
- `Waste.java` - Waste model class
